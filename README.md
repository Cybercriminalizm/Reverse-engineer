</p>Overview

A static-analysis toolkit for Windows PE malware research and file investigation.

Features

- PE32 / PE32+ analysis
- MD5 / SHA-1 / SHA-256 hashing
- Section & entropy analysis
- Import & export inspection
- Suspicious API detection
- String extraction
- URL / domain / IP detection
- Registry & persistence indicators
- YARA scanning
- JSON reporting
- Local report viewer

Safety

Static analysis only.

- No sample execution
- No sample modification
- No process injection
- No persistence
- No payload deployment

«Static indicators are research evidence, not automatic proof of malicious activity.»
